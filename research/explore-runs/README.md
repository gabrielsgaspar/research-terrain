# Explore runs

One record per run of the `explore-run` workflow, written by the workflow:
`<idea>/<run id>.md` (summary) and `<idea>/<run id>.json` (results). Every
run is kept, including failed ideas, so the number of analyses tried on the
exploration half is visible when results are reported.

People merge the record PR after adding a dated entry to
`research/lessons.md` and updating the idea file.
