# Task: the incumbency-curse gate: counts, validity by the design's own model, the lagged placebo and power at h = 0.135 (explore, idea 0012)

## Goal

A new explore script, `explore/0012_incumbency_gate.py`, on the
exploration half. At the fixed bandwidth h = 0.135 with a triangular
kernel, it:

- counts close races per election;
- tests validity with the design's own model (decision 0017);
- estimates the placebo jump in `party_held_mayor_lag`;
- computes the minimum detectable H1 difference;
- shows decision 0008's window table, as information only.

It reports every field twice: for all rows, and for the S2 sample (rows
with `finalist_eligible` true). It reads **no column measured at e+4 and
no amendment money**. Its `results.json` carries the five fields step
s2's kill rules read. Campaign
`research/campaigns/0014-incumbency-curse/campaign.md`, step s1. Step s2
runs it through `explore-run`. Step s3's script loads this one and reuses
its functions (listed under "Functions s3 reuses").

### Facts about the data (`data/contracts/mayor_incumbency_panel.md`)

- Two rows per race: a race is (`election`, `cd_ibge`). `margin` is the
  row's finalist's votes minus the other's, over valid votes, so a race's
  two margins add to 0, and `win` = `margin` > 0. A tie has both margins
  0 and no winner.
- Exploration-half races per election (build manifest, run 44766227487):
  2004 2,695; 2008 2,625; 2012 2,669; 2016 2,671; 2020 2,685. Campaign
  0012's gate counted 6,060 races within |margin| ≤ 10% over the five
  elections.
- `party_held_mayor_lag` (bool) is false where there was no e-4 result.
  `fin_age` can be null. `bench_fed` (int) is null for 2004 and 2008.
  `finalist_eligible` (bool) is null where the finalist has neither key
  (10 rows in 2012).
- `ln_pop` and `n_mayor_cands` are the same for both rows of a race.

### The design (fixed before any data is read; idea 0012)

- **Races and draws.** `race` = 0..R-1 over sorted (`election`,
  `cd_ibge`), every election together. `sign_draws(R)`: one (2,000, R)
  matrix of ±1, seed **20261122**, drawn once and used for every
  estimate. A re-flip multiplies both margins of a race by its sign, and
  `win` is recomputed as flipped margin > 0. |margin| does not change, so
  the kernel weights do not change under a re-flip.
- **Kernel weights** (`kernel_weights(margin, h, kernel)`):
  - `"triangular"`: w = 1 − |margin| / h on rows with |margin| < h; rows
    with |margin| ≥ h are not in the fit.
  - `"uniform"`: w = 1 on rows with |margin| ≤ h (+1e-12); others out.
  - The design's kernel is triangular with **h = 0.135** (Klašnja and
    Titiunik's). The uniform kernel exists for step s3's robustness fits.
- **The model** (`fit`), on rows inside the kernel with a non-null Y,
  weighted least squares with the kernel weights:
  - Y = Σ_c 1[cell = c]·(a_c + g_c·margin + d_c·win·margin) + Σ_G
    b_G·win·1[cell ∈ G];
  - the cell column is `election` by default; the caller may name another
    column (step s3 passes election × connected). G is a group of cell
    values given by the caller; rows outside every group are dropped;
  - standard errors clustered by `cd_ibge`, CR1: scores X_i·w_i·e_i,
    bread (X'WX)⁻¹, factor G_c/(G_c−1) × (N−1)/(N−K), N the rows in the
    fit. This is what `pyfixest.feols(..., weights=..., vcov={"CRV1":
    "cd_ibge"})` computes;
  - `ri_draws` refits the model under each of the 2,000 re-flips and
    returns the draws of any linear combination of the b's (NaN where
    singular).
  - RI p = (1 + #{|draw| ≥ |observed|}) / 2001, two-sided.
- **Counts (k4)**, at h, per election 2004-2020: races with |margin| < h,
  rows, ties, eligible-finalist rows. `counts.min_cycle_races_h` = the
  smallest race count of 2008, 2012, 2016 and 2020 (2004 is reported,
  not used).
- **Balance (k1)**, decision 0017 point 2. For each predetermined
  covariate as Y, all rows, the model with one group:
  - `fin_female`, `fin_higher_ed`, `finalist_eligible` (0/1) and
    `fin_age` (years): elections 2008-2020, one group {2008, 2012, 2016,
    2020};
  - `bench_fed_pos` = 1[`bench_fed` > 0]: elections 2012-2020, one group
    {2012, 2016, 2020};
  - a row with a null Y leaves that covariate only;
  - for each: b, clustered se, RI p, units, races;
  - `balance.omnibus_p`: the smallest of the five RI p's, set against the
    re-flip distribution of the smallest p (each draw's p for covariate j
    is #{draws with |b_j| ≥ that draw's |b_j|} / 2001, as `balance` in the
    0011 gate computes it), = (1 + #{draws whose smallest p ≤ the observed
    smallest p}) / 2001. Also `balance.min_p` and
    `balance.min_p_covariate`.
- **Placebo (k2).** Y = `party_held_mayor_lag`, all rows, elections
  2004-2020 in one group: b, clustered se, RI p, units, races.
  `placebo.fail` = 1 if |b| > 0.05 **and** RI p < 0.05, else 0 (an int).
  Also b and se for each election on its own (reported only).
- **Power (k3).** The H1 difference is b_post − b_pre, groups pre =
  {2008, 2012, 2016}, post = {2020}, all rows. The gate cannot read the
  outcome, so Y = `party_held_mayor_lag` stands in:
  - `power.sd_h1` = SD (ddof 1) of the finite re-flip draws of b_post −
    b_pre;
  - `power.var_stand_in` = p(1 − p), p the unweighted mean of the
    stand-in over the rows of that fit;
  - `power.scale` = sqrt(0.25 / `power.var_stand_in`);
  - `power.mde_h1` = 2.80 × `power.sd_h1` × `power.scale` (2.80 = z
    0.975 + z 0.80: two-sided alpha 0.05, power 80%), so it holds for any
    0/1 outcome.
  - Also `power.mean_stand_in` (= p).
- **Decision 0008's table (information only; decision 0017 point 6).**
  Load `explore/0011_incumbency_gate.py` with importlib (the `_load`
  pattern of `explore/0006_effects.py`) and call its `choose_window(panel,
  draws)` with this script's panel and draws. Write its `grid` under
  `window.table` (per window `races`, `units`, `omnibus_p`, `min_p`,
  `min_p_covariate`) and its `found` and `h_pct` as
  `window.rule_0008_found` and `window.rule_0008_h_pct`. They choose
  nothing and stop nothing.
- **The S2 sample.** Every field above (counts, balance, placebo, power,
  window table) again on rows with `finalist_eligible` true only, under
  `s2_sample`, with the same draws (re-flips by race). Its balance drops
  `finalist_eligible` (true on every row), so its omnibus p covers four
  covariates. These fields are reported, never read by a kill rule.

## Done when

1. On a synthetic two-rows-per-race panel built in the test, `fit` with
   the triangular kernel and with the uniform kernel matches
   `pyfixest.feols` with `weights=` and `vcov={"CRV1": "cd_ibge"}` on the
   same rows and design columns: every b and clustered se within a
   relative 1e-6. Also with `cell` set to a second column.
2. `kernel_weights`: 1 − |m|/h inside, rows at |m| ≥ h excluded for the
   triangular kernel; 1 on |m| ≤ h for the uniform one.
3. A re-flip swaps the winner of a race (the flipped `win` of its two
   rows are each other's original) and leaves the weights unchanged.
4. `fit` recovers a planted jump within 10%.
5. Balance: with a jump planted in `fin_female` at the cutoff,
   `balance.omnibus_p` < 0.05; with no jump planted, it is ≥ 0.05 under
   the fixed seed. `bench_fed_pos` uses only 2012-2020 rows.
6. `placebo.fail` is 1 only when both |b| > 0.05 and RI p < 0.05 (a test
   with each of the four combinations, using the function that decides
   it).
7. `power.mde_h1` = 2.80 × `power.sd_h1` × sqrt(0.25 /
   `power.var_stand_in`).
8. `counts.min_cycle_races_h` is the minimum over 2008-2020 only: a test
   with 2004 smallest.
9. `READ_COLUMNS` holds no `*_next`, `party_next` or `amend_after_*`
   column (a test reads it).
10. Rows outside the exploration half are dropped before anything is
    computed (test).
11. The `s2_sample` fields use only `finalist_eligible` rows (test).
12. `results.json` carries `balance.omnibus_p`, `placebo.fail`,
    `power.mde_h1`, `counts.min_cycle_races_h` and `estimates.finite`,
    and parses as standard JSON.
13. `uv run ruff check .`, `uv run ruff format --check .` and `uv run
    pytest` pass.
