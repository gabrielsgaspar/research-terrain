# Task: Explore: the incumbency gate with a uniform kernel at 10% (explore, fork f1 of campaign 0014)

## Goal

Re-run the gate of campaign 0014 (step s2, `explore/0012_incumbency_gate.py`) with one change: a uniform kernel with |margin| <= 0.10 in place of the triangular kernel at h = 0.135. The run inherits s2's kill rules unchanged.

## Idea

Run 45246860634 passed the gate at the triangular h = 0.135. Its decision-0008 table (information only) shows the uniform 10% window with a four-covariate omnibus p of 0.0185. Uniform 10% is one of s4's robustness fits. This fork checks whether that design passes the gate's own tests (the five predetermined covariates, the lagged placebo with its size condition, the H1 MDE, the counts), so the close-out knows how much weight that robustness fit can carry.

## In scope

- `explore/0012_incumbency_gate_uniform10_f1.py`: a thin script that loads `explore/0012_incumbency_gate.py` with `importlib` (as that script loads the 0011 gate) and reuses its `load_panel`, `prepare`, `sign_draws`, `counts_at`, `balance_at`, `placebo_at`, `power_at`, `window_table` and the finiteness check. It calls them with `h = 0.10` and `kernel = "uniform"` (rows with |margin| <= 0.10, as `kernel_weights` already defines). It restricts to the exploration half through `terrain.explore` (`exploration_municipalities`, `restrict`) and writes with `write_results`. Same panel, same `READ_COLUMNS` (no column measured at e+4, no amendment money), same seed 20261122, same 2,000 re-flips by race, same covariates, same clustering, same S2-sample block.
- Keys written to results.json, at the parent's dotted paths: `balance.omnibus_p`, `balance.min_p`, `balance.min_p_covariate`, `balance.covariates.*`; `placebo.fail`, `placebo.b`, `placebo.se`, `placebo.ri_p`, `placebo.by_election.*`; `power.mde_h1`, `power.sd_h1`, `power.mean_stand_in`, `power.var_stand_in`, `power.scale`; `counts.min_cycle_races_h`, `counts.races_h.*`, `counts.rows_h.*`, `counts.ties_h.*`, `counts.eligible_rows_h.*` (here "inside h" means inside the 10% uniform window); `estimates.finite`; `design.h` (0.10), `design.kernel` ("uniform"), `design.seed`, `design.draws`; `s2_sample.counts`, `s2_sample.balance`, `s2_sample.placebo`, `s2_sample.power` with the same keys; and `window` / `s2_sample.window` as the parent writes them (information only).
- `tests/test_explore_incumbency_gate_uniform10_f1.py`: synthetic tests showing that the script passes `kernel="uniform"` and `h=0.10` to every fit, that a row at |margin| = 0.10 is in and one just above is out, that every key the s2 kill rules read is written at its dotted path, and that the exploration-half restriction is applied.

## Out of scope

- Any change to `explore/0012_incumbency_gate.py`, its tests, the campaign file or any other existing file.
- Any outcome at e+4, any amendment money, any other bandwidth or kernel, any other covariate set or sample.
- Any threshold of its own: the kill rules are s2's, copied by code.

## What differs from the parent

Only the kernel and bandwidth: uniform with |margin| <= 0.10 in place of triangular with h = 0.135, in every fit of the gate (counts, balance, placebo, power, for all rows and for the S2 sample). Everything else (data, columns read, covariates, re-flips, seed, clustering, MDE formula, placebo size condition, output keys) is the same as step s2.
