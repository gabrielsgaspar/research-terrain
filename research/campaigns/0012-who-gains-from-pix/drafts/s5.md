# Task: the mayoral incumbency gate: window, races per election, H1 power and the lagged placebo (explore, idea 0011)

## Goal

A new explore script, `explore/0011_incumbency_gate.py`, on the
exploration half. It:

- chooses the close-race window h by decision 0008's balance rule;
- counts races per election at h;
- computes the minimum detectable H1 difference;
- estimates the placebo jump in `party_held_mayor_lag`.

It reads **no outcome at e+4** and no amendment money. Its `results.json`
carries the five fields step s6's kill rules read. Campaign
`research/campaigns/0012-who-gains-from-pix/campaign.md`, step s5. Step s6
runs it through `explore-run`. Step s7's script reads s6's run record and
reuses this script's functions (`choose_window`, `sign_draws`, `fit`,
`ri_draws`).

### Facts about the data (`data/contracts/mayor_incumbency_panel.md`)

- Two rows per race: a race is (`election`, `cd_ibge`). The rows hold the
  two finalists' parties. `margin` is the row's finalist's votes minus
  the other's, over valid votes, so a race's two margins add to 0, and
  `win` = `margin` > 0. A tie has both margins 0 and no winner.
- Exploration-half races per election in PR #436's dry run: 2004 2,695;
  2008 2,625; 2012 2,669; 2016 2,671; 2020 2,685.
- `party_held_mayor_lag` (bool) is false where there was no e-4 result.
  `fin_age` can be null. `bench_fed` is null for 2004 and 2008.
- `ln_pop` and `n_mayor_cands` are the same for both rows of a race.

### The design (fixed)

- **Races and draws.** `race` = 0..R-1 over sorted (`election`,
  `cd_ibge`), every election together. `sign_draws(R)`: one (2,000, R)
  matrix of ±1, seed **20261120**, used for every window and estimate. A
  re-flip multiplies both margins of a race by its sign, and `win` is
  recomputed as flipped margin > 0.
- **Window (k1).** The grid of the 0009 gate: 0.5%, 1%, 2%, 3%, 4%, 5%,
  7.5% and 10% (`w0_5pct` ... `w10pct`).
  - At each window, take the rows with |margin| ≤ w and, for each
    covariate, the winner-minus-loser difference in means with its raw
    randomisation p. Covariates: `fin_female`, `fin_age`,
    `fin_higher_ed`, `party_held_mayor_lag`, as 0 or 1 where boolean. A
    row with a null covariate leaves that covariate only.
  - The omnibus p is the 0009 gate's (minimum p across covariates, set
    against the re-flip distribution of that minimum), with all five
    elections pooled.
  - h is the widest window with omnibus p ≥ 0.15 whose smaller windows
    all pass. If 0.5% fails, `window.found` = 0, and h = 0.5% is used for
    the other fields.
  - `ln_pop` and `n_mayor_cands` are not tested (equal within a race).
    Report their means at h.
- **Balance by election (reported, not used to choose):** the same table
  for each election separately, at each window.
- **The model** (`fit`), on rows with |margin| ≤ h and a non-null Y:
  - Y = Σ_e 1[election = e]·(a_e + g_e·margin + d_e·win·margin) + Σ_G
    b_G·win·1[election ∈ G];
  - G is a group of elections given by the caller; elections outside
    every group are dropped;
  - OLS; standard errors clustered by `cd_ibge` (CR1: G_c/(G_c-1) ×
    (N-1)/(N-K)).
  - `ri_draws` refits it under each re-flip and returns the 2,000 draws
    of any linear combination of the b's.
  - RI p = (1 + #{|draw| ≥ |observed|}) / 2001.
- **Counts (k2).** Races with |margin| ≤ h per election (both rows
  inside: a race's margins have the same absolute value).
  `counts.min_cycle_races_h` = the smallest of the four elections 2008,
  2012, 2016 and 2020. Also the rows, the ties and the eligible-finalist
  rows (`finalist_eligible` true) per election at h.
- **Power (k3).** The H1 difference is b_post − b_pre, with groups pre =
  {2008, 2012, 2016} and post = {2020}. The gate cannot read its outcome,
  so it uses Y = `party_held_mayor_lag` (0/1) as the stand-in:
  - `power.sd_h1` = SD of the re-flip draws of b_post − b_pre at h;
  - `power.mde_h1` = 3.083 × `power.sd_h1` (z 0.9875 + z 0.80: two-sided
    alpha 0.025, power 80%).
  - Also `power.mean_stand_in`, the mean of the stand-in Y on those rows.
- **Placebo (k4).** Y = `party_held_mayor_lag`, one group = all five
  elections, at h:
  - `placebo.lag.b`, `.se`, `.ri_p`, `.n_units`, `.n_races`;
  - `placebo.lag_abs` = |b|.
  - The same b for each election (reported only).

### `results.json` keys (exact; no dots inside a key)

- `window.found` (0/1, **k1**), `window.h_pct` (null if not found),
  `window.grid.<w>.omnibus_p`, `.min_p`, `.min_p_covariate`, `.races`,
  `.units`, `.diff.<covariate>`, `.p.<covariate>`,
  `window.by_election.e<year>.<w>.omnibus_p` and `.races`.
- `counts.min_cycle_races_h` (int, **k2**), `counts.races_h.e<year>`,
  `counts.rows_h.e<year>`, `counts.ties_h.e<year>`,
  `counts.eligible_rows_h.e<year>` for each of the five elections.
- `power.mde_h1` (**k3**), `power.sd_h1`, `power.mean_stand_in`.
- `placebo.lag_abs` (**k4**), `placebo.lag.b`, `.se`, `.ri_p`,
  `.n_units`, `.n_races`, `placebo.by_election.e<year>.b` and `.se`.
- `descriptive.ln_pop_mean_h`, `descriptive.n_mayor_cands_mean_h`.
- `estimates.finite` (bool, **k5**): true only if every number under
  `power` and `placebo` is finite.

Non-finite numbers are written as `null` and make `estimates.finite`
false. The k1-k4 fields are never null: if one cannot be computed,
raise.

## Done when

1. A synthetic two-rows-per-race panel built in the test, five elections:
   - with balanced covariates, the widest window (10%) is chosen;
   - with winners' `party_held_mayor_lag` planted much higher than
     losers' only for 1% < |margin| ≤ 2%, h is 1% (the rule stops at the
     first failure);
   - with that imbalance planted at every margin, `window.found` is 0.
2. A re-flip swaps the winner of a race: the flipped `win` of the two
   rows are each other's original.
3. `fit` on a planted jump recovers b within 10%. Its clustered SE
   matches a hand-computed CR1 SE on a tiny panel (two clusters of
   several rows).
4. `counts.min_cycle_races_h` is the minimum over 2008-2020 only (2004 is
   counted but not used): a test with 2004 smallest.
5. `power.mde_h1` equals 3.083 × the SD of the draws of b_post − b_pre.
6. The script never reads a `*_next`, `party_next` or `amend_after_*`
   column: a test reads its `READ_COLUMNS` and fails if one is there.
7. Rows outside the exploration half are dropped before anything is
   computed (test).
8. `results.json` carries every key the kill rules read
   (`window.found`, `counts.min_cycle_races_h`, `power.mde_h1`,
   `placebo.lag_abs`, `estimates.finite`) and parses as standard JSON.
9. `uv run ruff check .`, `uv run ruff format --check .` and `uv run pytest`
   pass.
