# Task: the amendments gate: window, close-race counts, power, placebos and the author link (explore, idea 0009)

## Goal

A new explore script, `explore/0009_amendments_gate.py`, on the exploration
half. It does five things:

- chooses the close-race window h by decision 0008's balance rule;
- counts close races;
- computes the first stage's power;
- estimates the two placebos;
- reports the deputy-author link.

It reads **no post-election outcome**. Its `results.json` carries the six
fields that step s7's kill rules read. Campaign
`research/campaigns/0009-amendments-ballot-box/campaign.md`, step s6. Step
s7 runs it through `explore-run`; step s8's script reuses its window
choice.

## Idea

Idea 0009 (`research/ideas/0009-amendments-ballot-box.md`); decisions 0003,
0008 (the window rule), 0011 (national scope). Models:

- `explore/0003_mayor_power.py` for race re-flips (`sign_draws`) and the MDE
  (`power_stats`: MDE = 2.8 × the SD of the re-flip distribution);
- `explore/0001_window.py` for the omnibus balance test.

Copy what is needed, or load it with the `_load` pattern of
`explore/0006_effects.py`. This is an **explore** task (label `explore`):
it may change only the two files below.

### Rules that bind this script

- **Exploration half, national:** `exploration_municipalities(store,
  national=True)`, then `restrict` on `cd_ibge` before anything else.
- **Data read (referee R2).** Only `amendments_panel` (derived):
  `panel_A`, `panel_B`, `panel_C` and `author_link`. From the panels it
  selects only these columns:
  - `cycle`, `m`, `cd_ibge`, `uf`, `deputy`;
  - `population_m`, `round`, `margin`, `win`;
  - `fin_female`, `fin_age`, `fin_higher_ed`, `party_held_mayor`;
  - `amend_pre_total`, `amend_pre_pix`;
  - `share_t0`.

  It never reads `amend_post_*`, `n_pay_post`, `ran_t1`, `votes_t1`,
  `valid_t1`, `share_t1` or `d_share`: those are outcomes. Put the selected
  columns in a module constant `READ_COLUMNS`.
- **Nothing beyond this issue (referee R7).**
- **Compute:** `numpy` and `polars` only; the fixed effects by within-
  deputy demeaning. Well inside 180 minutes.

### Definitions (fixed)

- **A race:** (`cycle`, `cd_ibge`). A unit is a row. Re-flipping a race
  multiplies `margin` by −1 and swaps `win` for every unit of that race.
- **Draws:** 2,000 sign vectors over races, seed 20261115. Use the same
  vectors for every covariate, window and estimate.
- **Model:** Y = b·win + g·margin + d·win·margin + deputy-by-cycle fixed
  effects (`deputy` is already cycle-specific), on units with |margin| ≤ w.
  Standard errors are clustered by `cd_ibge`.
  - `ri_p` = (1 + #{|b_draw| ≥ |b|}) / 2001.
- **Pre-election amendments:** `y_pre` = `amend_pre_total` /
  `population_m` × 1,000 (reais per 1,000 inhabitants, the 21 months
  before the mayoral election).
- **Window grid:** 0.5, 1, 2, 3, 4, 5, 7.5 and 10% (keys `w0_5pct`,
  `w1pct`, `w2pct`, `w3pct`, `w4pct`, `w5pct`, `w7_5pct`, `w10pct`).
- **Window choice (decision 0008's rule):**
  - Per window and covariate: the win-minus-lose difference in unit means,
    and its randomisation p from the draws.
  - Covariates: `fin_female`, `fin_age`, `fin_higher_ed`,
    `party_held_mayor` and ln(`population_m`). Units with a null covariate
    are left out of that covariate only.
  - Omnibus p per window: the minimum p across the five covariates, set
    against the draws' distribution of that minimum.
  - h is the widest window with omnibus p ≥ 0.15 whose smaller windows all
    pass.
  - If 0.5% fails, no window is chosen: `window.found` is 0, and every other
    rule field is computed at 0.5% so that it is still a number.
  - Expose this as a function `choose_window(panel, draws) -> dict`; step
    s8 calls it.
- **Power (kill rule k3):** at h, the first-stage model with Y = `y_pre`.
  - mde = 2.8 × SD of b over the draws.
  - `power.mde_share` = mde / the mean of `y_pre` over the units at h.
- **Placebos:** at h, the model with two outcomes:
  - Y = `y_pre`;
  - Y = `share_t0` (the deputy's vote share at the previous general
    election).
  - For each: b, the clustered SE, `ri_p`, the mean of Y at h, and
    |b| / mean.
- **The 5% check:** the same counts, power and placebos at 5%, reported
  only (no rule reads them).
- **Author link (kill rule k6):** from `author_link`, per cycle,
  share = deputies / (authors − senators). `link.author_share` is the
  smallest of the three cycles.

### `results.json` keys (exact; no dots inside a key)

- `window.found` (int 0 or 1, **k1**), `window.h_pct` (float, or null when
  not found), `window.grid.<w>.omnibus_p`, `.min_p`, `.min_p_covariate`,
  `.races`, `.units`, and `.diff.<covariate>` / `.p.<covariate>` for the
  five covariates (`fin_female`, `fin_age`, `fin_higher_ed`,
  `party_held_mayor`, `ln_population`).
- `counts.races_h` (int, **k2**): distinct races at h with at least one
  unit; `counts.units_h`, `counts.deputies_h`, `counts.min_cycle_races_h`,
  `counts.by_cycle.<A|B|C>.races_h` and `.units_h`, `counts.races_5pct`,
  `counts.units_5pct`.
- `power.mde_share` (float, **k3**), `power.mde`, `power.sd_ri`,
  `power.mean`, `power.at_5pct.mde_share`.
- `placebo.amend_share_abs` (float, **k4**), `placebo.amend_b`,
  `placebo.amend_se`, `placebo.amend_ri_p`, `placebo.amend_mean`.
- `placebo.vote_share_abs` (float, **k5**), `placebo.vote_b`,
  `placebo.vote_se`, `placebo.vote_ri_p`, `placebo.vote_mean`.
- `placebo.at_5pct.amend_share_abs`, `placebo.at_5pct.vote_share_abs`.
- `link.author_share` (float, **k6**), and
  `link.by_cycle.<A|B|C>.share`, `.authors`, `.deputies`, `.senators`,
  `.ambiguous`, `.unmatched`.
- `estimates.finite` (bool): true only if every estimate above was finite.

Non-finite numbers are written as `null`. The six kill-rule fields are
never null: if one cannot be computed, the script raises, so the run fails
visibly.

`summary.md`:

- the window table;
- the chosen h;
- counts by cycle, power, placebos and the link;
- a line that a placebo that passes is not proof of balance;
- a line that nothing on the exploration half is a finding.

## Out of scope

- Any post-election outcome, the first stage or reduced form (step s8),
  coalitions, any window not in the grid, the confirmation half.

## Done when

1. A synthetic panel built in the test (three cycles, 300 races, two to
   four deputies per race) gives the following:
   - With a covariate imbalance planted only beyond 4%, `choose_window`
     returns 4%. With imbalance at 0.5%, `window.found` is 0, and the other
     rule fields are still numbers.
   - A planted placebo jump of 50% of the mean gives
     `placebo.amend_share_abs` near 0.5 (within 0.1).
2. `READ_COLUMNS` contains none of the post-election columns listed above
   (test).
3. Rows outside the exploration half are dropped before anything else
   (test).
4. `results.json` has every key a kill rule reads (`window.found`,
   `counts.races_h`, `power.mde_share`, `placebo.amend_share_abs`,
   `placebo.vote_share_abs`, `link.author_share`) as numbers. It parses as
   standard JSON (no `NaN`).
5. `uv run ruff check .`, `uv run ruff format --check .` and `uv run pytest`
   pass.
