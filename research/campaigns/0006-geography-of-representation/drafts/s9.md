# Task: match polling places to INEP schools (build, idea 0006)

## Goal

A build, `school_polling_match`, that matches each polling place to an
INEP school with a confidence level, so that idea 0006 can read the
facilities of the school that is the polling place. It reads no facility
field and stores no name or address. Campaign
`research/campaigns/0006-geography-of-representation/campaign.md`, step s9.
Step s10 runs it through `data-pipeline`.

## Idea

Idea 0006 (`research/ideas/0006-geography-of-representation.md`), decision
0011. The inputs are the national `polling_places` (step s1 makes it
national, with `nr_cep`; step s4 builds it) and `inep_school_catalogue`
(step s6 writes the acquirer, step s8 runs it). Their columns are in
`data/contracts/polling_places.md` and
`data/contracts/inep_school_catalogue.md`. Matching is not an outcome
(decision 0003), so the table holds both halves. This is a **build** task:
it may change exactly the files below.

### Build `school_polling_match`

One output Parquet per election year 2008, 2012, 2016, 2020 and 2024:
`school_polling_match_<year>.parquet`.

**Normalising text** (`normalise`):

- upper case; accents removed (NFKD);
- every character that is not a letter or digit becomes a space; single
  spaces.

For names, also drop every one-letter token and these tokens:
`ESCOLA ESC EMEF EMEI EMEB EMEIEF EEEF EEEFM EE EM EEM EF MUNICIPAL MUN
ESTADUAL EST COLEGIO COL UNIDADE ESCOLAR UE CENTRO EDUCACIONAL CE INSTITUTO
DE DA DO DAS DOS ENSINO FUNDAMENTAL MEDIO INFANTIL BASICA PROF PROFA
PROFESSOR PROFESSORA DR DRA DONA DOM`. An address is `endereco` plus
`numero` (school) or `ds_endereco` (polling place), normalised with no
tokens dropped.

**Scores** for each pair (polling place, school in the same `cd_ibge` =
`id_municipio`):

- `name_sim`: `difflib.SequenceMatcher(None, a, b).ratio()` of the
  normalised names; 0 when either is empty.
- `addr_sim`: the same on the normalised addresses.
- `cep_equal`: both CEPs present and equal (polling place `nr_cep`, school
  `cep`).
- `dist_km`: great-circle distance between the polling place's `lat`/`long`
  and the school's coordinates, when both exist; otherwise null.
  `near` = `dist_km` ≤ 1.

**Confidence** of a pair:

- `high`: `name_sim` ≥ 0.90 and (`cep_equal` or `addr_sim` ≥ 0.80 or `near`);
- `medium`: not high, and either `name_sim` ≥ 0.90, or `name_sim` ≥ 0.75 and
  (`cep_equal` or `near`);
- `low`: neither, and `name_sim` ≥ 0.60;
- otherwise no match.

Each polling place keeps its best school, ordered by:

1. confidence (high, medium, low);
2. `name_sim`, then `addr_sim`;
3. smaller `dist_km` (null last);
4. `id_escola`.

A place with no pair at `low` or better keeps one row with a null school and
`confidence` `none`. These rules and thresholds are fixed here, before any
real match is run; changing them needs a new task.

**Output columns:**

- the polling-place key: `ano`, `cd_ibge`, `sg_ue`, `nr_zona`,
  `nr_local_votacao`;
- `id_escola`, `rede` (from the catalogue), `confidence`;
- `name_sim`, `addr_sim`, `cep_equal`, `dist_km`;
- `n_candidates`: schools in the municipality with `name_sim` ≥ 0.60.

Names and addresses are not copied to the output.

**Manifest notes:**

- per year: places, and the share at each confidence level, overall and by
  state. This includes the high+medium match rate by state and year, which
  Gabriel asked for.
- places that share one school (count).

Matching is not an outcome, so the notes may cover both halves.

**Output path:** `content_hash` of the input SHA-256s, the years, and the
code of the build and of every `terrain` module it imports.

**Speed:** compare only within a municipality. Compute `name_sim` against
every school of the municipality; compute `addr_sim` and `dist_km` only for
schools with `name_sim` ≥ 0.60.

## Out of scope

- Reading any facility field (`inep_schools`), and splitting anything by
  half: that is `place_outcomes` (step s14).
- Geocoding schools from their addresses.
- Any file outside the five above.

## Done when

1. The catalog entry loads; `tests/test_acquire.py` still passes.
2. Match tests on cases built in the test:
   - "E M E F PROF JOSE DA SILVA" matches "ESCOLA MUNICIPAL PROFESSOR JOSE
     DA SILVA" with the same CEP as `high`;
   - the same name 3 km away with no CEP or address match is `medium`;
   - "IGREJA BATISTA CENTRAL" matches nothing (`none`);
   - a school in another municipality is never a candidate;
   - two equally good schools are broken by `id_escola`;
   - the output carries no name or address column.

   world built in the test.
4. `uv run ruff check .`, `uv run ruff format --check .` and `uv run pytest`
   pass.
