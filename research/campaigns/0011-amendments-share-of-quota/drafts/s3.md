# Task: the amendments gate for the share and log outcomes: window, counts, power, placebos and the link by money (explore, idea 0010)

## Goal

A new explore script, `explore/0010_amendments_gate.py`, on the
exploration half. It does five things:

- chooses the close-race window h by decision 0008's balance rule;
- counts close races;
- computes the first-stage power of two outcomes, `share` and `log_pc`;
- estimates the placebos;
- reports the deputy-author link by money.

It reads **no post-election outcome**. Its `results.json` carries the six
fields that step s4's kill rules read. Campaign
`research/campaigns/0011-amendments-share-of-quota/campaign.md`, step s3.
Step s4 runs it through `explore-run`; step s5's script reads s4's run
record and reuses this script's functions.

### Facts about the data (`data/contracts/amendments_panel.md`)

- `amend_pre_share` (Float64): the municipality's share, in [0, 1], of all
  the individual amendment money the deputy paid in the pre window to
  identified municipalities. Null where the deputy paid nothing in the
  window. In the real-file dry run (PR #421, both halves) it was null on
  13,841 rows in cycle A, 1,501 in B and 2,122 in C; cycle A has 16,533
  exploration-half rows, B 12,830, C 17,067.
- `amend_pre_log_pc` (Float64): ln(1 + reais per inhabitant in the pre
  window), at least 0. Null where `population_m` is null or 0.
- `author_link.parquet`: one row per cycle (A, B, C), counts as Int64 and
  `money_share` as Float64 (null if its denominator is 0). In the dry run
  `money_share` was 0.915, 0.926 and 0.932.

### Definitions (fixed)

- **Races, units, draws, model, window choice:** 0009's, through the
  reused functions. A race is (`cycle`, `cd_ibge`). 2,000 sign vectors,
  seed 20261115, the same for every covariate, window, outcome and
  estimate. Y = b·win + g·margin + d·win·margin + deputy-by-cycle fixed
  effects on |margin| ≤ w; errors clustered by `cd_ibge`. A unit with a
  null outcome leaves that outcome's fit only (0009's `estimate` does
  this).
- **The two outcomes** (module constant `OUTCOMES`, in this order):
  - `share`: Y = `amend_pre_share`. Its statistic is relative:
    `stat` = |b| / mean of Y over the fit's units at the window.
  - `log_pc`: Y = `amend_pre_log_pc`. Its statistic is absolute:
    `stat` = |b|.
  - Limit for both power and placebo: 0.25 for `share`, 0.223 for
    `log_pc` (module constant `LIMITS`).
- **Power (kill rule k3):** at h, for each outcome:
  - alpha 0.025, two-sided, one test per outcome; power 80%:
    `MDE_K` = z(0.9875) + z(0.80) = 2.2414 + 0.8416 = 3.0830 (write it
    from these two quantiles; no `scipy`);
  - mde = `MDE_K` × the SD of b over the 2,000 re-flips (0009's `sd_ri`);
  - `mde_stat` = mde / mean for `share`, mde for `log_pc`;
  - `powered` = 1 if `mde_stat` is finite and ≤ its limit, else 0;
  - `power.n_powered` = the number of powered outcomes (0, 1 or 2).
- **Placebos (kill rules k4, k5):** at h.
  - For each outcome: b, the clustered SE, `ri_p`, the mean, the units,
    `stat` and `fails` = 1 if `stat` > its limit, else 0.
  - `placebo.powered_failing` = the number of outcomes with `powered` 1
    and `fails` 1. If a powered outcome's `stat` is not finite, raise.
  - The vote placebo, Y = `share_t0`, exactly as 0009:
    `placebo.vote_share_abs` = |b| / mean.
- **The 5% check:** `mde_stat` and the placebo `stat` of each outcome,
  and `vote_share_abs`, at 5%; reported only (no rule reads them).
- **Link (kill rule k6):** from `author_link`:
  - `link.money_share` = the smallest `money_share` of the three cycles.
    If a cycle's row is missing, repeated, or its `money_share` is null,
    raise.
  - Also 0009's head-count share, deputies / (authors − senators), as
    `link.author_share` (reported only).

### `results.json` keys (exact; no dots inside a key)

- `window.*` and `counts.*`: the same keys as 0009's script.
- `power.alpha` (0.025), `power.mde_k`, `power.n_powered` (int, **k3**);
  for `<o>` in `share`, `log_pc`: `power.outcomes.<o>.mde`, `.sd_ri`,
  `.mean`, `.units`, `.mde_stat`, `.limit`, `.powered` (int 0 or 1);
  `power.at_5pct.<o>.mde_stat`.
- `placebo.powered_failing` (int, **k4**); for each `<o>`:
  `placebo.outcomes.<o>.b`, `.se`, `.ri_p`, `.mean`, `.units`, `.stat`,
  `.limit`, `.fails` (int 0 or 1); `placebo.at_5pct.<o>.stat`.
- `placebo.vote_share_abs` (float, **k5**), `placebo.vote_b`,
  `placebo.vote_se`, `placebo.vote_ri_p`, `placebo.vote_mean`,
  `placebo.at_5pct.vote_share_abs`.
- `link.money_share` (float, **k6**), `link.author_share`, and
  `link.by_cycle.<A|B|C>.money_share`, `.share`, `.authors`, `.deputies`,
  `.senators`, `.ambiguous`, `.unmatched`, `.ties_broken`,
  `.non_current_authors`, `.chamber_links`.
- `estimates.finite` (bool): true only if every estimate above was finite.

Non-finite numbers are written as `null`. The six kill-rule fields
(`window.found`, `counts.races_h`, `power.n_powered`,
`placebo.powered_failing`, `placebo.vote_share_abs`, `link.money_share`)
are never null: if one cannot be computed, the script raises, so the run
fails visibly. Put them in a module constant `RULE_FIELDS`.

`summary.md`:

- the window table and the chosen h;
- counts by cycle;
- one table per outcome: mde, mean, `mde_stat`, limit, powered; placebo b,
  SE, RI p, `stat`, limit, fails;
- the vote placebo and the link table by cycle (money share and counts);
- a line that the two outcomes were chosen after campaign 0010's gate
  failed on per-capita reais;
- a line that a placebo that passes is not proof of balance;
- a line that nothing on the exploration half is a finding.

## Done when

1. A synthetic panel built in the test (three cycles, 300 races, two to
   four deputies per race, with `amend_pre_share`, `amend_pre_log_pc` and a
   three-row `author_link`) gives the following:
   - With a covariate imbalance planted only beyond 4%, the chosen window
     is 4%. With imbalance at 0.5%, `window.found` is 0, and the other
     rule fields are still numbers.
   - A planted placebo jump in `amend_pre_share` of 50% of its mean gives
     `placebo.outcomes.share.stat` near 0.5 (within 0.1); a planted jump of
     0.5 in `amend_pre_log_pc` gives `placebo.outcomes.log_pc.stat` near
     0.5 (within 0.1).
   - A world where `share` is very noisy and `log_pc` is precise gives
     `power.n_powered` 1 with `share` unpowered and `log_pc` powered; a
     placebo jump planted only in the unpowered outcome leaves
     `placebo.powered_failing` at 0, and the same jump in the powered one
     makes it 1.
   - Null `amend_pre_share` rows are left out of the `share` fit only
     (`units` drops, the `log_pc` fit is unchanged).
   - `link.money_share` is the smallest of the three cycles; a null
     `money_share` raises.
2. `MDE_K` is 3.0830 to four decimals (test).
3. `READ_COLUMNS` contains none of the post-election columns listed above
   (test).
4. Rows outside the exploration half are dropped before anything else
   (test).
5. `results.json` has every key a kill rule reads (`RULE_FIELDS`) as
   numbers, and parses as standard JSON (no `NaN`).
6. `uv run ruff check .`, `uv run ruff format --check .` and `uv run pytest`
   pass.
