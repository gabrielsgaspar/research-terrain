# Task: acquire ANM SIGMINE mining processes without holder names (build, idea 0007)

## Goal

A new acquirer for `anm_sigmine`: every **active** mining process from ANM's
SIGMINE ArcGIS feature service, with polygons and a fixed list of fields,
stored as one Parquet file in raw. The holder-name field `NOME` is never
requested and never stored. Campaign
`research/campaigns/0007-gold-and-the-ballot/campaign.md`, step s1. Step s2
runs it through `data-pipeline`. Step s6 builds `gold_exposure` from it.

## Idea

Idea 0007 (`research/ideas/0007-gold-and-the-ballot.md`). This is a **build**
task: it may change exactly the files below. Models to follow:

- `src/terrain/inep.py`: a custom acquirer that writes Parquet and a
  manifest, with its "unchanged" check;
- `src/terrain/acquire.py`: dated raw folders, write-once, upload only
  after every check passes;
- `src/terrain/http.py`: requests.

  (dadosabertos.anm.gov.br) answered HTTP 403 to scripts on 2026-11-11.

### `terrain.anm`

- **TLS.** `geo.anm.gov.br` sends its certificate without the intermediate
  (Sectigo Public Server Authentication CA OV R36, issued by Sectigo Public
  Server Authentication Root R46, valid to 2036-03-21).
  1. At run time, download the DER file from `tls_intermediate.url`.
  2. Compute its SHA-256 and compare it with `tls_intermediate.sha256`. On a
     mismatch, stop before any other request.
  3. Build `ssl.create_default_context()` and add the certificate with
     `load_verify_locations(cadata=<DER bytes>)`. Set
     `ssl.VERIFY_X509_PARTIAL_CHAIN`, so that the pinned intermediate is a
     trust anchor even if the runner lacks the R46 root.
  4. Hostname checking and `CERT_REQUIRED` stay on.
  
  No certificate is committed. The HTTP fetch is injected, so tests use a
  fake.
- **Fields.** Request exactly `out_fields`. Refuse to run if `out_fields`
  contains `NOME` or any name starting with `NOME`: hard-coded in
  `terrain.anm`, not configurable. Also check that every returned feature
  has exactly the requested attributes, so no extra field is ever stored.
- **Paging.**
  1. First `query?where=1=1&returnCountOnly=true&f=json` gives N.
  2. Then pages of `page_size`:
     - parameters `where=1=1`, `outFields`, `orderByFields=OBJECTID`,
       `resultOffset`, `resultRecordCount`, `outSR`, `returnGeometry=true`;
     - `f=geojson`, until a page is empty or short.
  3. Then check:
     - total records equal N;
     - `OBJECTID` is unique;
     - N ≥ `min_records`.
  
  If the counts differ (the service is regenerated daily), repeat the
  whole paging once. Then fail with both counts.
- **Retries.** A failed page is retried up to 3 times, with a pause in
  between. An ArcGIS error body (`{"error": ...}` with HTTP 200) is a
  failure.
- **Output.** One file, `sigmine_active.parquet`, one row per process, with
  columns:
  - the `out_fields`, lower-cased;
  - `geometry_wkb` (binary, WKB of the polygon or multipolygon, SIRGAS 2000
    degrees, from GeoJSON via `shapely`).
  
  Invalid geometries are kept as given and counted in the manifest notes.
  Do not repair them here; the build does.
- **Manifest notes:** records; records by `UF`; gold records; gold records
  with `ano` < 2000; records without `ano`; invalid geometries; the
  intermediate's SHA-256.
- **Raw is write-once:** a new dated folder under `gcs`. Upload the Parquet
  and the manifest only after every check passed. The "unchanged" rule
  follows `terrain.inep`: if the newest folder has the same record count
  and the same per-`UF` counts, report unchanged and upload nothing.

## Done when

1. A fake service with 3 pages (2000, 2000, 7 records) gives a Parquet of
   4,007 rows with exactly the expected columns. A count mismatch is
   repaged once, then raises. Duplicate `OBJECTID` raises. An `{"error"}`
   body raises after 3 retries.
2. A catalog `out_fields` with `NOME` raises before any request. A feature
   carrying an attribute not requested raises.
3. A wrong intermediate SHA-256 raises before any request to the layer.
   The SSL context is built with `cadata` and the partial-chain flag.
   Test this on the context object; no network.
4. Nothing is uploaded when any check fails (fake store). The manifest
   notes carry the counts listed above.
5. The real catalog entry loads; `tests/test_acquire.py` passes unchanged
   (no URL in code).
6. `uv run ruff check .`, `uv run ruff format --check .` and `uv run pytest`
   pass.
