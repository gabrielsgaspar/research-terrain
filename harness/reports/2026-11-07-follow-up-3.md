## 2. Results

### The estimator

**What it is.** Its core, `frozen.py`, is a verbatim copy of the 72 explore
functions and classes behind run 42298466207, balance, kill criterion 1 and
alignment. A test checks each against its original's syntax tree.
`analysis.py` takes the treatment once, before any outcome is read. Then it:
- stops at kill criterion 1 if that is met;
- prints the balance table and omnibus p;
- computes every estimate of run 42298466207, plus the direct placebo, the
  Z-adjusted estimates and the alignment split.

**On synthetic data:**
- Its numbers equal `explore/0001_effects.py`'s exactly (all eleven
  estimates, the dropped cells and the type counts).
- Kill criterion 1, alignment kinds and balance equal their own scripts.
- Through `confirm-run`, the shuffled run finds nothing. Through `unblind`,
  the real run finds the synthetic effect (RI p at most 0.01 with 200
  draws).
- Two real runs give identical numbers.

**On real data: not yet.** `explore/0001_registered_check.py` will compare
every number of run 42298466207 (and kill criterion 1 of run 41839642406) at
0.50% on the exploration half, and print only the comparison. explore-run
runs only merged code, so this waits for your merge of #236 (issue #241).

**Never at 0.25%.** The estimator refuses that window outside `confirm-run`
and `unblind`, and no test uses it.

### Determinism

The real unblind run is deterministic:
- the inputs are fixed build files;
- the re-flips use seed 20261106, and the shuffle a seed fixed by the spec's
  hash;
- every ledger number is recorded to 12 significant digits, so a different
  floating-point summation order cannot change it.

A manual rerun, by deleting `ledger/unblind-<spec>`, is allowed only if the
first run produced no ledger entry.
