# Task: generate research/INDEX.md from the records

## Goal

One generated page that lists every idea and decision with its status and
links, plus the latest lessons and explore runs, so planners and reviewers
read one file first. Build plan item 2.3. Needs task 11 merged.

## In scope

- `scripts/build_index.py`: reads the front matter of `research/ideas/` and
  `research/decisions/` (task 11's format), the dated headings of
  `research/lessons.md`, and `research/explore-runs/<idea>/*.md`, and writes
  `research/INDEX.md`: an ideas table (id, title, status, updated, datasets),
  a decisions table (id, title, status, date), the ten newest lessons
  (date and heading, linked), and explore runs per idea (count and newest).
  Sorted by id; no timestamps of its own, so the same inputs give the same
  file.
- `research/INDEX.md`, generated by the script.
- `tests/test_index.py`: the committed `research/INDEX.md` equals what the
  script generates now (so CI fails when someone forgets to regenerate), and
  the tables on records built in the test.

Expected files (three): `scripts/build_index.py`, `research/INDEX.md`,
`tests/test_index.py`.

## Out of scope

- Changing workflows or prompts to read the index (a person does that,
  build plan item 2.4).

## Done when

1. `uv run python scripts/build_index.py` regenerates `research/INDEX.md`
   with no diff.
2. Tests show a new idea appears in the table and a changed status changes
   the file.
3. `uv run ruff check .`, `uv run ruff format --check .` and `uv run pytest`
   pass.
