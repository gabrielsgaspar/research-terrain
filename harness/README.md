# Harness

The planner, builder and reviewer prompts currently live inside the workflow
files in `.github/workflows/`, adapted from Alteram
(https://github.com/gabrielsgaspar/alteram). Prompts that grow beyond a few
paragraphs move here as Markdown files, and changes to them are their own
task.

`BUILD_PLAN.md`, `AUTONOMY_LOG.md` and `reports/` are historical records,
kept because decisions cite them. The current rules are in `AGENTS.md` and
`research/decisions/0010-campaigns.md`.
